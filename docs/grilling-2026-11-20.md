# Decisões de partida (grilling de 2026-11-20)

## Destino

v1 usável numa sessão real. Você pede no Claude ("somos eu, Ana e Leo, 2h, algo leve") e recebe um top 5 com linhas de evidência, a partir dos perfis importados. Depois registra o feedback, que alimenta a justiça entre sessões.

## Decisões

| Tema               | Decisão                                                                                                                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Público            | Você e amigos, uso não comercial                                                                                                                                                                                         |
| Interface          | Servidor MCP em TypeScript + skill. O MCP chama a CLI em Python (`python -m filmes ... --json`) como subprocesso                                                                                                         |
| Motor              | Híbrido: grafo e algoritmo escolhem os candidatos; o LLM interpreta o pedido, reordena e redige a explicação só a partir das evidências                                                                                  |
| Evidência          | Uma linha por motivo: `Evidência: <fato> · Fonte: <...> · Força: forte/moderada/fraca · Tipo: metadado/nota própria/nota de amigo/review/declarado/palpite`. Modelo herdado do match-reply e do pesquisa-relacionamentos |
| Verificação        | Obrigatória: toda linha aponta para um fato no banco com fonte e data; sem fato, o motivo vira "palpite"                                                                                                                 |
| Dados              | Pessoas, grupos, sessões e preferências declaradas em Markdown versionado. Catálogo e grafo num SQLite derivado e reconstruível                                                                                          |
| Fontes v1          | Wikidata (grafo, ponte de IDs, ClassInd), TMDB, CSV do Letterboxd, Trakt, Does the Dog Die, datasets do IMDb, MovieLens, OMDb (notas RT/Metacritic)                                                                      |
| Catálogo           | Completo ("tudo de tudo") se for viável; plano B: sob demanda + vizinhança no grafo                                                                                                                                      |
| Escopo             | Só filmes; sem filtro de onde assistir                                                                                                                                                                                   |
| Grupo              | Desde a v1. Gosto dos amigos entra por import Letterboxd/Trakt, questionário rápido, descrição feita pelo dono e feedback pós-sessão                                                                                     |
| Contexto de sessão | Quem está e quantos; tempo e energia; restrições (criança, legenda/dublagem, gatilhos); ocasião                                                                                                                          |
| Regra de grupo     | Configurável por sessão. Vetos rígidos sempre antes. Padrão: média sem miséria + justiça entre sessões                                                                                                                   |
| Grupo ou sozinho   | Features do filme + sinais extraídos de reviews + histórico das sessões, cada sinal guardado como evidência                                                                                                              |
| Stack              | Motor em Python; MCP em TypeScript                                                                                                                                                                                       |

## Névoa (vira tickets)

- research: viabilidade do catálogo completo (volume, tempo de ingestão, limites do TMDB)
- research: de onde extrair sinais de "bom em grupo ou sozinho" nas reviews
- research: mapear CSV do Letterboxd para IDs TMDB/IMDb (Wikidata P6127, letterboxd-csv-imdb-tmdb-mapper)
- research: algoritmo candidato (CF no MovieLens, embeddings pykeen, caminhos hopwise/PGPR)
- grilling + domain-modeling: glossário (Pessoa, Sessão, Evidência, Força, Veto)
- grilling: critérios de Força por tipo de evidência
- grilling: modelo de justiça entre sessões
- prototype: formato da resposta no Claude (top 5 + evidências)
- prototype: fluxo de feedback pós-sessão
